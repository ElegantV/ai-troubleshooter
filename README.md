# AI 问题排查助手（原型 v0.2）

面向数据异常与批量作业失败场景的智能排查工具原型，对应"AI靶场"实训需求表——资源交付中心《AI问题排查助手》场景。

## 架构（五层）

前端已迁移至 **Vue 3 + Element Plus**（源码 `frontend/`，Vite 构建产物输出到 `public/` 由 Express 托管）：

```bash
npm run build:ui   # 前端构建（需先 cd frontend && npm install）
npm run dev:ui     # 前端开发模式（5173 端口，/api 代理到 3000）
```

页面：智能排查 / 能力图示 / 案例库 / 排查历史（审计留痕可视化，可复看任意历史报告）

```
应用交互层   Web 页面（public/index.html，原生 JS）
智能体编排层 src/agent/  固定工作流：输入理解→场景路由→规则归因→案例检索→验证SQL→报告
知识/存储层  SQLite（data/assistant.db）：血缘图+作业链路+案例库+审计日志
离线加工层   src/pipeline/  血缘解析·图融合·日志结构化（LLM 血缘解析接口已预留）
数据采集层   src/collectors/  原型读 data/raw 模拟源；真实环境替换为
             元数据平台/调度系统API/日志平台/工单系统API/版本库
侧挂         安全治理（只读SQL/审计）· LLM适配层（src/agent/llm.js，默认关闭）
```

## 运行

```bash
npm run build      # 构建知识库（只刷新知识表；案例库/审计记录/用户全部保留）
npm start          # 启动服务 http://localhost:3000
node test_api.js   # 端到端测试（需服务已启动）
```

依赖：Node.js ≥ 22（使用内置 node:sqlite，无需数据库安装）、express。

## 已实现能力

- 作业失败排查：输入失败作业/报错 → 上游链路状态回溯、错误码归因（含近期日志历史回溯）、上游告警线索、历史案例匹配
- 数据异常排查：输入异常表/字段 → 产出作业状态核查、行数骤降检测、下游影响传导分析；仅输入字段时自动定位候选表
- **存储过程分析（不限输入）**：粘贴任意 SQL 片段 → 解析源/目标表与 JOIN 关系、关联行内作业、展开上下游血缘、展示相关表结构（列/类型/约束/说明），并做静态风险分析（LEFT JOIN 空值风险、分区过滤缺失、重跑幂等性、血缘覆盖缺口），给出排查方向建议
- 输入自动路由：SQL 片段/表名/字段/作业名/报错日志混输均可，系统识别后走对应分析流程
- **能力图示页**：血缘×链路关系图（SVG，按数仓分层布局，真实知识库数据）+ 三大能力（血缘/链路/案例关联）的概念说明与真实关联演示，演示卡带"试一试"一键运行
- 候选原因按置信度排序，每条附证据引用（日志行/工单/血缘边），可解释可审计
- 只读验证 SQL 模板生成（分区行数对比/新鲜度/空值检查）
- **案例录入**：案例库页签手工录入已解决问题（现象/根因/解决方式），关联作业/表/错误码可留空由系统从文本自动识别；查重防重复录入，录入后立即参与排查匹配
- 反馈沉淀闭环：确认原因后自动写入案例库，后续排查自动关联（数据飞轮）
- 查询全程审计留痕（query_log 表）
- 知识库规模：18 个错误码 + 21 条历史工单（覆盖死锁、表空间、快照过旧、文件编码/超时、码值缺失、对账不平、负金额、重复数据等真实银行跑批场景）+ 3 个跑批日故障剧本

## 认证与操作归属（v0.3）

访问需注册/登录（页面右上角，注册即自动登录）。会话令牌持久化于 SQLite（`sessions` 表，7 天有效，密码 scrypt 加盐哈希）。所有 API（排查/反馈/案例录入）要求登录，案例与审计记录均归属到操作人（`cases.created_by` / `query_log.user_name`）；生产环境替换点：`src/auth.js` 换为行内 LDAP/SSO 单点登录，归属落库逻辑不变。

## 接入 LLM（可选）

编辑 `src/config.js` 的 `LLM` 配置（OpenAI 兼容格式，行内网关/智谱 GLM/Ollama 均可），置 `enabled: true`。接入后用于：报告结论归纳、动态 SQL 血缘解析兜底、输入实体识别增强。

## 真实环境替换点

| 原型 | 生产替换 |
|---|---|
| data/raw 模拟文件 | 元数据平台 / 调度系统 API / 日志平台 / 工单系统 API / Git 版本库 |
| SQLite 图查询 | Neo4j 等图数据库 |
| BM25 关键词检索 | 知识库平台向量检索（RAG） |
| 规则归因引擎 | 规则生成候选 + LLM 归因复核（workflow.js 已预留调用点） |
